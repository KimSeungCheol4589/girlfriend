## 최종 검토와 남은 관문

전체 DATE 제품의 독립 검토는 fc4da6f를 대상으로 승인됐다. 이후 9467970의 캘린더 모바일 수정은 실제 인증 375px 화면에서 통과했고, 단위 828개·lint·typecheck·production build도 통과했다. 새 독립 delta 검토 a03f8416-9719-446f-8104-e6ddcea8af29는 제품 수정 자체에 차단 결함을 찾지 않았으나 테스트·진단·인수인계의 P2 4건을 지적했다. c47da60으로 수정 후 새 검토 6498301d-0deb-4deb-b312-d745804b5857가 코드·테스트·진단의 지적 해소를 확인했다. 남은 인수인계 이력 P2는 304eb34에서 문서만 정정했다. 새 독립 문서 검토 f3202576-a1dc-47ff-9467-28c9d17e9825(c47da60→304eb34)는 P0/P1/P2 없음으로 승인했다. 전체 제품 검토와 후속 delta 검토를 합쳐 최종 후보의 차단 지적은 모두 해소됐다.

c47da60에서 바뀐 단위 테스트 2개를 총괄이 재실행해 통과했다. 실제 배지 2개를 메모리상 삭제한 변이에서 개수 0이 되어 단언이 실패하는 것도 확인했다. 제품 코드는 9467970 이후 변경되지 않아 기존 전체 검증을 유효하게 유지한다.

보강 DATE 연결·취소·부분 성공 재시도 3개와 수정 후 모바일 1개는 모두 통과했다. 테스트 helper의 잘못된 컬럼과 fixture 정리 순서는 앞선 독립 검토 및 실제 실행으로 수정·확인됐다. 복제 DOM 검사만으로 실제 인증 화면 통과를 주장하지 않는다.

## DB 백업·복원 보완 검증

격리 SOURCE/TARGET에서 앱 22개 migration과 합성 fixture로 백업·단일 트랜잭션 복원을 실행했다. 양쪽 불변식은 각각 117개 통과했고, 저장된 데이터 지문 99줄은 총괄이 파일을 직접 비교해 차이 0을 확인했다. 양쪽 로그의 성공 117개·오류 0도 재집계했다. 신규 환경은 network none·포트 미공개·독립 tmpfs였으며 기존 데이터나 볼륨을 복사하지 않았다. Auth/Storage의 스키마 정의만 호환 baseline으로 사용했다.

자동 러너는 **88 OK / 1 FAIL**로 완전 PASS가 아니다. 네 테이블의 NULL ACL과 명시적 기본 ACL 표현 차이에서 중단했다. DB 담당은 coalesce(relacl, acldefault('r', relowner))로 계산한 유효 권한을 별도 비교해 차이 0을 확인했다. 이 수동 관측은 자동 PASS와 구분하며 원시 해시가 파일로 남지 않았다는 한계도 유지한다. 최종 러너 독립 검토 세션 58fcccc3-c9d4-4130-a699-f954a47acfcc는 실행 승인했다.

증거: DB 담당의 제외된 QA-001-db-restore-result-20260926.md 및 QA-001-db-runner-20260926/manual-verification-record.md, 실행 증거 폴더 qa001-db-runner-20260926-185738-f465c169. 임시 SOURCE/TARGET 제거·기존 6개 서비스 보존을 담당이 확인했다. 자동 러너를 재사용하려면 ACL 표현 정규화와 별도 검토가 필요하다. 제품 변경은 없다.

## 범위·한계

- 로컬 MVP 검증과 dev 통합이 대상이다. main 승격·공개 배포·운영 SMTP/재인증 설정·운영 재해복구 승인은 포함하지 않는다.
- DB 논리 복원, 실제 인증 회귀, 사진 바이트 복원은 별도 시험이다. 이를 운영 전체 복구 보증으로 합치지 않는다. Storage 내부 객체 ID·생성시각·owner는 재생성되며 앱의 asset/path/추억 참조와 접근 경계를 검증했다.
- Chromium 모바일 뷰포트 통과는 실제 휴대폰 전 기종 검증을 의미하지 않는다.
- 원본별 목록 상한/정렬 안내 등 비차단 P3는 후속 개선이며 MVP 범위를 확대하지 않는다.
- 최종 제출은 304eb34이며 제품 코드는 9467970 이후 동일하다. 이후 테스트·진단·문서 수정은 별도 독립 검토로 승인됐다. dev 통합 SHA는 TASKS.md에 기록한다.
